# 小禾学伴

面向小学生的学习与教研应用。首版使用四年级上册语文、数学、英语三科课程，可完成题库组卷、在线作答、帮助记录、学习报告、错题订正、知识证据和教研审核。

> 最终交付目标已明确为 Android 与 iOS 手机 App。本目录是已有 Web/后端原型；双端原生工程见 `../xiaohe-mobile/`，总计划见 `../APP-实施计划.md`。

## 启动

需要 Node.js 22.13 或更新版本。已安装依赖时直接运行：

```sh
npm run dev -- --port 5173 --hostname 127.0.0.1
```

打开终端输出的网址，点击登录进入本地模拟账户。模拟登录仅在本地开发启用，生产由 Sites 验证身份。

首次拉取源码后：

```sh
npm run install:ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_great_wallop.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_melodic_alex_power.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_history_upload_fence.sql
npm run dev -- --port 5173 --hostname 127.0.0.1
```

迁移只在尚未应用的本地数据库执行一次；新增迁移按文件顺序应用。生产迁移由 Sites 部署执行，生产与本地数据完全独立。

## 已实现

- 学生首页、知识地图、试卷配置与预览、同难度换题另存、在线练习、草稿保存和本机恢复。
- 首页按**三条学段线**组织：小学四年级（语文/数学/英语）、上海初中（中考考纲 33 个知识点）、上海高中（高考考纲 15 个知识点），每条线显示已加入学习的知识点与待订正错题；学段是**全局状态**（写在地址里），顶栏可随时切换，知识地图、组卷、单题练习、错题本都跟着走，不用每处重选。
- 知识地图按科目—单元—知识点浏览并查看逐点解释；每个单元可「开始学习本单元」解锁，也可直接点「**做这一组**」当场出卷（解锁 + 出题合成一步）。组卷先选学段（一张试卷只装同一学科、同一学段），再从静态内容库按知识点取已审核题目（小学每点 32 道 = 解答填空 30 + 选择 2，初中与高中每点 20 道 = 解答填空 15 + 选择 5），按题族去重并避开已看帮助与近期作答；卷面上每四轮安排一轮优先取选择题，比例接近真实考卷。“我的练习”另提供 57 道与知识点对应的原创自练题，答案草稿按工作区与用户保存在当前浏览器，不计入正式学习报告。教材目录来源见[教材目录与习题入库](docs/curriculum-and-paper-sources.md)。
- 正确/独立/提示/讲解分项报告；错题订正保留原答；题族和答案曝光用于过滤新题证据。
- 图片原稿真实存入 R2，人工核对题库原题并回传纸面答案；纸面帮助状态为未知。
- 分别打开学生卷、解析卷，可通过浏览器打印或另存 PDF；看解析先记录曝光。
- 绑定明确原卷/题库版本的私人会话、显式提示/讲解、可恢复草稿、本人呈现偏好与删除影响预览；手写求助摘要先预览再单独保存到授权工作区收件箱，未发送外部通知。本机 App 摘要明确尚未发送。
- 教研题库筛选、标注、新版本、独立审核、发布、停用、证据日志和内容清单导出。
- **真题考情与出处索引**（学习端）：卷面结构（时长、分值、题型分布，官方公布与第三方口径分开标注）、上海市教育考试院各年「专家点评」里的考点出处索引，以及每道题对应的考点出处。**不收录真题原文** —— 考试院只发布点评、不发布试卷原件，商业题库上的「真题」版权归属不明；小学更没有全区统考真题（上海明令禁止），网传的是校本卷。
- 组卷首屏给两个预设：「按我的薄弱点」（默认，星级不足 3 星与待订正错题优先）与「按教材章节」（手动勾选）；错题本按学段分区。
- **错因标签**：每道错题可标「概念不清 / 计算失误 / 审题偏差 / 步骤遗漏 / 公式记错」（学生自己选，系统不替他猜），标过的错题按原因聚成「按错因看」，每组直接出「按这组错因练 N 道」—— 同一题族 14 天内不重复出题，所以组卷范围会带上同单元的已解锁知识点。
- 组卷可按**卷面结构**出卷（上海中考数学 25 题结构：选 6 / 填 12 / 解 7；高考数学、合格考同理），卷面结构只决定题型比例与卷面信息，题量仍按选的数量。
- 工作区成员邀请、邮箱绑定一次性凭证、撤销授权；学生、家长、教师、编辑、审核人按角色访问。
- 已提交证据逐条/多选删除：先预览报告、星级、复查、本人关联会话/摘要及显式所选照片的影响，再绑定修订确认。已删除正文移除，保留无正文删除凭据及最小已见/帮助资格事实；照片立即撤销访问，存储回收失败可重试。
- 服务端过滤未授权答案/草稿/照片/私聊，D1 revision CAS同时校验成员权限；上传文件按学习档案归属鉴权。
- 本机照片识别核对的共享领域：原图、设备原始行、人工改字与逐题核对分开保存，固定候选题版本后分批入档；未匹配条目保留草稿，同图识别副本纳入历史删除。设备调用与验收由手机工程负责，Web 不提供 OCR 入口。

## 当前边界

这是私有试点版本，不是完整学校生产系统。工作区所有者可以邀请其他角色，每个档案最多一位学生。邀请不改变外层 Sites 访问范围；目前站点仍为所有者私有，其他账号要先获得站点访问权限。App 将采用独立身份与服务端，不依赖此网页登录。自己创建的草稿不能通过更换角色自审。

当前 Web 自动 OCR、自由生成式对话和语音未接入。共享领域已支持可信本机设备识别结果的保存与逐题核对，只有本机调用可以进入；这不表示 Web 或设备 OCR 已验收。拍照题目仍需本人核对并明确选择固定题库版本，学伴使用审核题库检索，不宣称已经接入生成模型。真实教材、授权题库、教研星级标准仍需提供和验证。

本地学伴行为及当时的浏览器验证范围见[学伴验收记录](docs/companion-web-validation.md)。证据更正支持申请、主动选原稿、独立教师复核、影响预览及统一有效结果；更正不覆盖原始提交和旧评定，另行确认历史删除时才移除所选作答及关联依据。受限图片接口按当前授权和当前登记双重检查。最新 **237/237** 项领域/Web 测试、类型检查、lint 和构建结果见[本机识别领域验证](docs/recognition-validation.md)，既有服务端删除边界见[历史删除验证记录](docs/history-web-validation.md)；本轮没有启动 Web 服务、浏览器实测或云部署。会话删除仍不删除原作答或另存摘要；历史删除是独立入口，范围在确认前逐项说明，不是清空整个学习空间。原生教师授权送达仍未完成，Android/iOS 设备状态以手机工程验收文档为准，iOS 仍未原生安装验证。

已接入五级掌握规则：讲解后完成、提示后完成、基础独立、不同情境稳定应用、间隔后独立迁移。教研端可编辑参数、试算、送审、独立复核、发布与切回旧版；每次正式重评追加历史及逐题依据。默认参数明确为未验证的内置试用配置，演示历史和纸面自述不计真实掌握。旧 `pilot-v2-max3` 结果保留，旧证据缺少的教学标签不回填。

间隔复查来自真实提交，按有效到期日开放，排除全部历史已见题族。静态内容库现按 105 个教材知识点编写原创题：小学 57 个知识点各 32 道（解答填空 30 + 选择 2），上海初中 33 个知识点与上海高中 15 个知识点各 20 道（解答填空 15 + 选择 5），共 2784 道，每道题是一个独立题族 —— 题族是升星的计量单位，「30 道」不等于「30 次可独立作答的练习」，复习轮次仍会消耗新题资格，需要持续扩充。Web 教师证据复核已接通；原文件配对导入/逐页校对/语义重复人工处理与教学有效性验证尚未完成。本地 Web 与原生 App 数据及规则不自动同步；本轮未发布云端。

当前按工作区文档存储，有容量配额；正式多人和多学校部署前需完善学校班级模型、实体分表、课程知识点配置、规则验证及数据归档。教学题目本身放在仓库内的静态内容库（见下节），不占用工作区容量 —— 工作区体积只与「这个学习者实际做过的题」成正比。

完整后续范围见 [实施计划](docs/implementation-plan.md)，验证记录见 [验证说明](docs/verification.md)。

## 静态内容库

教学题目放在**仓库内**的静态内容库，而不是工作区里：

```
content/bank/{chinese,math,english}.json   小学题库（仓库内只读，内容寻址）
content/bank/junior-math.json             上海初中数学（按中考考纲编写）
content/bank/senior-math.json             上海高中数学（按高考考纲编写）
content/bank/batch-<unitId>.json           各批次的原始产出（合并来源）
content/bank/figures*.json                 插图规格（由生成脚本画成 SVG）
content/bank/manifest.json                 库版本与摘要
```

- **为什么分开**：整个工作区是 D1 里的一行 JSON（4 MB 上限），每次接口都全量传输。题目若全进工作区，2784 道题会占掉一半预算并逼近上限。静态库不进工作区，工作区体积只与「这个学习者实际做过的题」成正比。
- **借阅即归档**：库题一旦被组进试卷，正文由 `ensureContent` 冻结进 `state.content.versions` —— 与工作区自建题走同一条归档链，「题正文不可原地覆盖」的约束不变。
- **不破坏审核分离**：库题带机器作者/审核标识（`bank-author-*` / `bank-check-*`），教研台凡展示库题计数处都标注「未经逐题人工复核」。
- **题族去重**：同一题族只计第一次独立新题，因此每个知识点的题量必须是有意义的题族数，而不是同一模板换数字。编写规范见[题目编写规范](docs/bank-authoring-spec.md)，上海初高中另见[上海考纲编写规范](docs/bank-authoring-spec-shanghai.md)，选择题另见[选择题编写规范](docs/bank-authoring-choice.md)。

### 学段

知识地图可切换三个学段，知识点 id 的格式是 `<学科>-<学段>-<单元>-<知识点>`（小学无学段段）：

| 学段 | 学科 | 知识点 | 说明 |
|---|---|---|---|
| 小学 | 语文 / 数学 / 英语 | 57 | 统编版、人教版、PEP 四年级上册 |
| 初中 | 数学 | 33 | **按上海市中考考纲的考点与题型结构编写**（数与式 8 / 函数 6 / 几何 10 / 统计与概率 3 / 综合与探究 6） |
| 高中 | 数学 | 15 | **按上海市高考考纲的考点与题型结构编写**（函数与导数 5 / 数列 2 / 立体几何 2 / 解析几何 2 / 概率统计 2 / 复数与三角 2） |

初高中的题目**全部原创**，不是历年真题，也不照抄教材原文；覆盖的是**考点与题型**（几何证明、新定义、动点、二次函数与几何综合、导数与切线、圆锥曲线定值定点、空间向量等），出处逐题标注在 `source` / `sourceScope` 字段里。几何证明题按「证明过程要点」判分，学生提交的是推理过程而非结论。

常用脚本：

```sh
node scripts/generate-illustrations.mjs          # 按 figures*.json 生成 SVG 到 public/illustrations/
node --experimental-strip-types scripts/merge-bank.mjs       # 合并各批次 → 学科文件 + 重算 manifest
node --experimental-strip-types scripts/validate-bank.mjs    # 题库质检（16 类检查 + 凑式检测 + 端到端内容包解析）
node --experimental-strip-types scripts/export-bank-packages.mjs   # 切成内容包写入相邻手机工程
node --experimental-strip-types scripts/align-difficulty.mjs      # 难度与任务类型对齐
```

知识地图里每个单元可「开始学习本单元」，解锁后该单元的知识点才进入组卷范围；组卷只从已审核题目中取，并按题族去重。

## 本地内容包与版本归档

教研数据版本页可导出已发布候选与显式选中的停用清单；任一候选缺少独立审核/任务/情境/来源范围等字段时整包拒绝。审核页可查询实际保存的归档，数据版本页只读展示批次及回退，不把导出当作应用。Web 没有内容包导入或回退操作入口。手机“我的 → 题库内容包”显式导入 JSON，批次独立保存在手机，不自动回传教研端。题目的先修条件目前仅为文字说明，尚无可执行的前置知识图谱。

可选样题源见 `lib/trial-content.ts`，范围见 `content-trial-notes.md`。运行 `node --experimental-strip-types scripts/export-trial-content.mjs` 将生成相邻手机工程 `content-packs/xiaohe-basic-trial-v1.json`（不修改档案）。这 9 题包含 8 个新结构候选和 1 个旧族子任务，未经人工教研验证。所有内容包都强制未签名/未验证声明；摘要校验不是发行人身份认证。实际浏览器验收与限制见 `docs/content-web-validation.md`。
