# 上海初高中数学 · 静态题库编写规范

本规范补充 [`bank-authoring-spec.md`](./bank-authoring-spec.md)（通用规范）。冲突时以本规范为准 —— 但**字段格式、硬约束、质检流程一律沿用通用规范**，只在这里没写到的部分补充。

---

## 0. 首先要说清楚的一件事

**这些题是「按上海市中考／高考数学考纲的考点与题型结构编写的原创题」，不是历年真题。**

- 不复制、不改写、不拼接任何教辅或真题原文。
- 覆盖的是**考点与题型**（这是最有价值的部分），不是具体那道题。
- 每道题的 `source` 写 `小禾教研原创 · 按上海中考考纲编写 · 非真题`，
  `sourceScope` 写 `上海市初中数学中考考点 · 原创编写，非真题原文 · 未人工逐题复核 · 教学有效性待教研验证`
  （高中同理，把「中考」换成「高考」）。
- `reviewNote` 沿用通用规范的原文。

**不要在题干里写「本题改编自 XX 年上海中考」「与真题类似」这类话** —— 题干要像一道独立成立的题。

## 2. 按上海卷的题型结构来组织

### 上海中考数学（`math-j-*`）

试卷结构：选择题 6 题、填空题 6 题、解答题（含几何证明、代数计算、实际应用、新定义／阅读理解、综合压轴）。

**每个单元的 15 道题要覆盖这些题型角色**，不要全是同一种：

| 任务类型 | 题型角色（按 `contextId` 体现） |
|---|---|
| `basic` | 单概念辨析、单步计算、性质直接应用 |
| `application` | 多步运算、实际情境建模、简单几何证明 |
| `transfer` | 综合题、跨章节、压轴题型（新定义、动点、二次函数与几何、参数探究、阅读理解） |

**必须包含的压轴题型**（分散在对应知识点，每个至少 1 道）：
- `math-j-5-quadratic-geometry`：二次函数图象与几何图形结合
- `math-j-5-moving-point`：动点运动中的长度、角度、面积
- `math-j-5-extreme`：几何最值（将军饮马、割补）
- `math-j-5-parameter`：含参讨论与取值范围
- `math-j-5-new-definition`：新定义问题（题干先给定义，再用定义解题）
- `math-j-5-reading`：阅读理解（读一段材料，再回答）

### 上海高中数学（`math-s-*`）

试卷结构：**没有选择题**；填空 12 分，解答题覆盖数列、立体几何、解析几何、函数与导数、概率统计、复数与三角。

| 任务类型 | 题型角色 |
|---|---|
| `basic` | 公式直接应用、概念题、单个性质的计算 |
| `application` | 多步骤推导、需要选择方法、综合计算 |
| `transfer` | 综合压轴：导数与不等式、解析几何定值定点、数列与不等式放缩、空间向量综合 |

## 3. 深度要求（最容易做偏的地方）

初高中的题**必须达到该年级的真实认知水平**，不能用小学题放大数字的方式凑数。

**初中（八九年级）**
- 可以用一元二次方程、勾股定理、相似三角形、锐角三角函数、圆与切线、二次函数图象与性质。
- 解答题允许 3–5 步推导。
- 几何证明题必须**真的需要推理**（不能一步得出）。
- 实际应用题要有**真实建模**（不是把小学应用题的数字改大）。

**高中（高一到高三）**
- 必须用到导数、指数对数、三角函数与恒等变换、空间向量、圆锥曲线、复数等。
- 解答题允许 5–8 步推导。
- 压轴题要有**分类讨论**、**含参**、**恒成立**、**定值定点**这类结构。
- 导数题要有定义域、单调性判别、极值最值的完整链条。

**反面例子（不要这样写）**：
- ❌「一个长方形长 24 厘米、宽 18 厘米，周长是多少」放进 `math-j-3-quadrilateral`
- ❌「求 y = x² 在 x = 3 处的函数值」放进 `math-s-1-function`（这太浅）
- ✅ 「已知二次函数 f(x) = x² − 4x + 3，求 f(2) 与 f(3)，并判断 f(x) 在区间 [1, 3] 上的最小值」放进 `math-j-2-quadratic`

## 4. 几何证明题的特殊写法（重要）

几何证明题是初高中的主力题型，但**学生提交的是证明过程，不是结论**，所以不能按数值题写。

**写法**：
- `answer` = **证明过程的关键步骤要点**，用全角竖线 `｜` 分隔。例如：
  ```
  AB∥CD｜∠B=∠2（内错角）｜∠1+∠2=180°（平行线性质）｜∠1=90°（已知）｜∠1+∠2=90°... 
  ```
  更实际的写法是把每个要点写成一小段，例：
  ```
  由对顶角相等得∠AOB=∠COD｜由AB∥CD得∠ABO=∠CAB... 
  ```
  要点数量控制在 **3–6 个**；判分按「｜」分开的要点命中一半即算对（坐标、向量这类答案另外按数字比对）。
- `steps[0]` = **第一步的依据**（写成文字或等式都可以）。例如 `"由 ∠AOB=∠COD（对顶角相等）"`。
- `steps` 其余步骤写推理链条，**必须有一条含「答：」**（例如 `"答：所以 △AOB ∽ △COD。"`）。
- `unit` = `""`。
- `hint` 提示该用哪个性质；`alternative` 给另一条证明路径。

**几何计算题**（求角度、长度、面积）则按普通数值题写：`answer` 是数值，`unit` 是「厘米」「度」等。

## 5. 等式与算术验算

沿用通用规范，但初高中常见**多步式子**：

- 等式支持括号与多运算符：`"(3 + 2) × 4 = 20"`、`"360 ÷ (12 - 2) = 36"`；也支持一元负号与负数结果：`"-5 + 5 = 0"`。
- 等号右边**不带单位**；左边**第一个数字最好出现在题干里**（出现在中间步骤里只记提示）。
- 结果必须等于 `answer`。
- 可验算的等式**不必是 `steps[0]`**；第一步可以是列式，算式写在第二、三步同样算数。
- **不许凑式**：`5 + 0 = 5`、`12 − 0 = 12` 这类「加（减）0 得原数」的等式会被判为没有实际计算，必须重写。
- 若是**证明题或读材料题**（答案不是一次运算能得的），把这一步写成文字说明即可，校验脚本会记提示让人工确认。
- 反过来，**不要为了迁就等式规则把题目问法改别扭**。如果一道题自然的问法是「求证 AB∥CD」，就用证明题写法（见第 4 节），不要改成问某个中间量；
  也**不要为了迁就等式规则在首步硬凑一个等式** —— 那会让校验脚本误以为这题验算过了。

## 6. 情境与图文

- 每点 15 道题覆盖 **10 个情境**（基础 2 + 应用 3 + 迁移 5），情境之间**问法与材料都要不同**。
- 情境 id 用英文 kebab-case，语义清楚（如 `math-j-3-circle__tangent-chord-angle`）。
- 初中几何题**需要图**（圆、切线、相似、锐角三角函数、二次函数图象、动点）。
- 配图规格写进 `content/bank/figures-<unitId>.json`，键 = 题目 `image` 路径去掉 `/illustrations/` 前缀和 `.svg` 后缀。
- 现有渲染器支持：`angle`、`rectangle`、`square`、`triangle`、`parallelogram`、`trapezoid`、`bars`、`grid`、`numberLine`。
- **图形内只允许 ASCII 数字与几何符号，绝不出现汉字或英文**（缺字体的机器会渲染成方块）。图上的类别标签用 A/B/C，中文说明写在题干里。
- 二次函数图象、圆与切线、立体几何目前**没有对应的渲染器** —— 这类题**先不要配图**，把数据写在题干里，或先扩渲染器。
- **写了 `image` 就必须真的有那个 SVG 文件**（校验脚本逐个检查），**题干写了「如图 / 图中」就必须有图**（没有图就别写「如图」）。两条都会判不通过。
- 平行线与截线、圆、坐标系这类几何图需要**先扩渲染器**（`scripts/generate-illustrations.mjs`）再配图，
  或者手写 SVG 落到 `public/illustrations/<unitId>/<slug>.svg`，并把规格同步写进 `content/bank/figures-<unitId>.json`。

## 7. 质量硬约束

沿用通用规范第 2、4、5、6、7、8 节，以下几点特别提醒：

1. **一题一族**：15 道题 = 15 个不同题型模板。**只换数字不算新题。**
2. **规范化题干全库唯一**（NFKC → 小写 → 去空白）。
3. **数字同形必须同题族**。
4. **算术自动验算**：能被验算的题，答案必须真的对。
5. **答案要唯一**：实际应用题与开放性问法要保证答案唯一（不要出「写出一种方法」这种题）。
6. **`prerequisites` 填真实依赖**：只填同单元或相邻单元的知识点 id（如 `math-j-3-circle` 依赖 `math-j-3-angle`）。
7. **不要超纲**：初中题不要用高中的导数；小学题不要出现在初高中题库里。
