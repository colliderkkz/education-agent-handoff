# 本机照片识别核对：共享领域验证

日期：2026-10-27。本记录验证共享 TypeScript 领域、权限投影、历史删除与构建，不表示 Web OCR 已接通，也不作为 Android 或 iOS 原生识别成功的证据。本轮未启动 Web 服务、未做浏览器操作、未发布云端。

## 已实现的范围

原图登记、设备识别原结果、逐题人工核对和正式提交分别保存。`WorkspaceState.recognition` 是可选的新档案；旧档案没有该字段时按空档案处理，不补造机器识别结果。

- 原图绑定 `uploadId` 和原文件 SHA-256 `imageDigest`。同文件登记别名或相同摘要不能建立第二份识别档案。
- 识别运行保存引擎、平台、版本、图像尺寸和有序行；每行只存文字、归一化左上角坐标及实际置信度或 `null`，不保存另一份全文或原生 JSON。当前中文 ML Kit 行置信度要求 `null`；Vision 可保留实际值。置信度不表示答案正确率。
- 人工条目分别保存原题号、来源行、题干、答案、过程、四项核对标记与题库候选。文字检索只返回候选，不自动证明同题，不自动从手写内容解析数学作答。
- 候选固定题库题号、版本及正文摘要，首次选择须与当前已发布、非作者审核的题目一致。保存后保留原题快照；题库后来升级不替换已选版本。学生可见的 `candidateSummary` 只含冻结题干、单位、题号与版本，答案和解析快照不进入投影。
- 首次保存，以及题干、答案、过程、来源行、题号或候选变化后，四项核对标记全部清除。用户需另一次明确核对后才能提交。
- 一张图可以分批提交已核对的条目；未匹配、空答案或未核对条目留作草稿，不生成错题或计分记录。每次报告按实际选择顺序固定题目与版本，不重复使用同一报告的题号位置。
- 入档复用原始纸面作答规则，建立条目到试卷、作答及证据的结构化关联。帮助状态为未知、独立程度未核实，不计独立掌握星级；设备文字识别不构成教师核验。

原来的 `homework.confirm` 与原卷纸面回传不代替这条流程。已绑定识别档案的照片及同文件别名不能再经旧入口重复入档；也不从旧 `paper.reason` 自由文字猜测历史照片关联。

## 动作与保存边界

| 动作 | 用途与约束 |
| --- | --- |
| `recognition.open` | 绑定已保存原图、摘要与开始时的历史删除代次，返回 capture ID |
| `recognition.run.save` | 接收可信本机适配层提供的真实设备结果；同时核对原图摘要、capture 修订和历史删除代次 |
| `recognition.match` | 只读文字候选，返回安全题目摘要与精确版本，不记录答案曝光 |
| `recognition.entry.save` | 按 capture 修订保存单条人工核对草稿，改内容清核对 |
| `recognition.submit` | 仅提交显式选择且全部核对的条目，返回实际报告 ID |

全部 `recognition.*` 动作都要求可信调用上下文 `channel === 'local'`，且角色只能为本人 student/owner。普通 Web 请求没有这个上下文，不能在请求体中伪造 `channel`、角色或设备来源。手机适配层负责调用设备能力、核对私有原文件并持久化；领域函数本身不调用相机、不读取图片、不访问 OCR 云服务。

写动作使用稳定请求编号与请求摘要；同请求重试返回已保存结果，内容冲突拒绝。凭据的返回 ID 必须指向本 capture 正确类型的运行、条目或报告，不能指向不存在或其他档案的结果。保存失败不以新请求自动覆盖旧草稿。开始时的历史删除代次用于阻止删除期间的晚到设备结果写回。

当前边界：每图最多 5 次原始识别、20 条核对条目；单次最多 300 行、每行 2000 个 UTF-16 字符、总文字 30000 个 UTF-16 字符；识别档案最多 100 图且序列化内容不超过 200 万字符。超过限制明确拒绝，不截断后伪称完整保存。

## 隐私与历史删除

识别原文和草稿只投影给其本人；其他所有者不会继承别人的识别档案，家长、教师、编辑、审核人不获得整份 OCR 数据。识别操作日志同样限制为本人可见。候选私有快照不出现在任何学生/所有者投影；派生摘要字段不能作为原始持久状态写入。

删除一条已提交识别证据时，除既有作答、更正和关联记录清理，还会：

1. 清除该条目的题干、答案、过程、核对状态、来源行和候选快照。
2. 清除同 capture 所有机器识别运行的行文字，包括旧识别、未分配行与共享行；保守清除同图所有未提交人工草稿，防止复制出的原答案残留。
3. 保留未选中的已提交人工答案，以及无正文运行/条目关联凭据。删除预览列出影响 capture、运行次数及额外草稿 ID，并明确范围。
4. 将 capture 标为已清理，禁止重新识别、新建/修改草稿及继续提交；旧请求重放不能恢复文字。相同图片摘要重新登记也不能绕过该限制。

照片仍需显式选择。未删提交、其他草稿/材料或文件别名仍有引用时保留原图；不把删 OCR 文字等同于删原图。仅选择删除一张尚无已提交条目的识别原图时，也清理其机器原文并在预览说明。实际文件清理仍由已持久化的历史删除任务执行，不删除系统相册、外部导出或备份。

## 尚未完成

Web/服务端自动识别仍未接入。本轮没有实现多页导入与裁切、旋转排序、自动题块切分、数学公式/竖式或手写答案的可靠结构化识别、自动同题判断，也没有新增云 OCR 或图片外传。低置信度、缺失文字和未匹配内容仍需人工核对；真实教材题库和教学有效性验证继续保留为后续范围。
