# 选择题编写规范（静态题库）

选择题单列一类，是因为它的**作答交互与判分路径**都和填空题不同：
学生看到的是单选按钮，提交的是**一个字母**；答案是一个字母，判分只认这一个字母。
本文件是 `docs/bank-authoring-spec.md`（通用规范）与 `docs/bank-authoring-spec-shanghai.md`（上海考纲规范）的补充。

---

## 1. 题量

| 学段 | 每知识点题量 | 其中选择题 |
|---|---|---|
| 小学四年级 | 32（解答填空 30 + 选择 2） | **2** |
| 上海初中 / 高中 | 20（解答填空 15 + 选择 5） | **5** |

选择题的 `answer` 一定是一个字母（A—D）；解答填空题的答案不是字母 —— 质检按这个区分两类。

---

## 2. 题面格式（必须能被选项解析器读出来）

```
<题干>（　　）。A．<选项一>　B．<选项二>　C．<选项三>　D．<选项四>
```

- 四个选项，标号**大写 A—D**，后面跟**全角句点 `．`**（`U+FF0E`）。
- 选项之间用**全角空格 `　`**（`U+3000`）分隔，也可以用空格，但不要换行。
- 题干末尾写 `（　　）`（全角括号 + 两个全角空格）。
- 选项解析器要求 A、B、C、D **连续**；漏一个标号或写错标点，整题会退化成普通文本题。

正文里如果出现英文缩写（例如 `A` 段、`B` 组），不要写成 `A.` `B.` 的形式，否则会被误读成选项。

---

## 3. 字段

选择题的字段与普通题一致，只有这几处不同：

| 字段 | 选择题怎么填 |
|---|---|
| `answer` | 单个字母 `"A"` / `"B"` / `"C"` / `"D"` |
| `unit` | `""`（答案是字母，没有单位） |
| `text` | 题干 + `（　　）。` + 四个选项 |
| `taskType` | `basic` / `application` / `transfer` 三选一，照实填难度角色 |
| `difficulty` | 与 `taskType` 一致：`basic→基础`、`application→巩固`、`transfer→挑战` |
| `contextId` | `<knowledgeId>__<kebab-case>`，**每道题各不相同** |
| `familyId` | `<knowledgeId>__fam-<编号>`，与该知识点已有题族不重号 |
| `id` | `bank-<knowledgeId>-c<01..05>`（或该学科现有编号规则的下一个） |
| `steps` | 三条，最后一条含「答：X。」 |
| `image` | 本轮**一律不配图**；题干里也不要写「如图」 |

---

## 4. 干扰项的质量要求（这一条最容易做砸）

- **三个干扰项都必须是「真实会犯的错」**：概念混淆、单位搞错、符号看漏、算错一步、选反了「充分/必要」…
- **不能一眼排除**：长度不能都和正确答案差很多；正确答案不能永远是「最长的那个」或「最短的那个」。
- **干扰项之间不能互相矛盾到只剩一个合理**；也不能出现两个都对的选项。
- 选项里如果有数字，数字要**贴着这个知识点的真实数据**，不要用 1、2、3、4 这种占位数字。

一个反例（干扰项一眼假）：

> 下列说法正确的是（　　）。A．三角形有 3 条边　B．三角形有 4 条边　C．三角形有 5 条边　D．三角形没有边

一个正例（干扰项都是真会犯的错）：

> 下列说法正确的是（　　）。A．对角线相等的平行四边形是矩形　B．对角线相等的平行四边形是菱形　C．对角线互相垂直的平行四边形是矩形　D．对角线互相平分的平行四边形是矩形

---

## 5. 答案字母的分布

- **小学每点 2 道**：两道题的答案字母**必须不同**（质检按知识点检查）。
- **上海每点 5 道**：同一单元内的答案字母不能全部相同；同一知识点内建议至少用到 3 个不同字母。
- 不要固定把正确选项排在 B 或 C —— 学生会看出规律。

---

## 6. 判分怎么走（质检会照这个验）

1. 选项解析器（`lib/choice.ts`，学生端与手机端共用）必须能解析出 **4 个**选项。
2. 正确答案必须在解析出的选项里。
3. 判分器（`lib/grading.ts`）必须**只**认这一个字母：选 A 对、选 B/C/D 都错。
4. 反过来也成立：**答案不是字母的题，题干里不能有 4 个选项** —— 否则卷面会渲染成单选，
   学生只能提交字母，而参考答案要的是一段话，怎么选都判错。

---

## 7. 交付前自检

```sh
node --experimental-strip-types scripts/merge-bank.mjs        # 合并批次 → 学科文件
node --experimental-strip-types scripts/validate-bank.mjs     # 题库质检
```

自检只看**属于你负责的知识点**的条目。全库其它条目此刻可能仍报「选择题不足」——
那是别的批次还没交付，不是你的问题。

写完用 `dir content\bank\batch-<你的文件>.json` 确认落盘再汇报：题数、每个知识点的情境清单、
答案字母分布、以及**哪些题的干扰项你觉得需要教研再确认**。
