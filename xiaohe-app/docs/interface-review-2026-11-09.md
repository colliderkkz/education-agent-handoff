# 功能分区与界面整理（2026-11-09）

依据：仓库 README、`APP-实施计划.md`、`docs/implementation-plan.md`，以及《小禾学伴V2.pdf》的原始功能流程。此次针对正在使用的 Web 工程；没有改动或重新构建原生 App，也没有发布云端。

## 新入口与功能去向

| 一级入口 | 负责的任务 |
| --- | --- |
| 学习首页 | 选择语数英课程、续接在途试卷、查看记录概况 |
| 知识地图 | 科目 → 单元 → 知识点解释 → 对应练习 |
| 我的练习 | 知识点练习 / 组卷训练 / 练习记录；拍照与回传作为任务入口 |
| 错题本 | 原始答案、订正、同类新题、原题帮助 |
| 我的 | 学习小结、档案、记录复核、记忆/历史管理、共享权限 |

学习帮助可从首页或原题上下文进入；拍照、帮助、复核与历史管理页提供返回所属分区的入口。保留旧 URL 和题号深链，试卷预览与报告返回练习记录。

教研模块分为内容制作（题库、提取校对、教学解法）、审核发布（审核、版本、评估）、课程与评价（课程、熟练度）。既有编辑/审核分离、权限和历史快照未更改。

## 本次修复

- 移除首页重复宣传、固定数学推荐和重复共享入口，以三科课程为主体。
- 将单题自练、组卷配置、试卷历史改为按任务显示，不再在一个长页面堆叠。
- 修复空知识点编号与未配置 practiceId 意外匹配导致默认选科错误；支持直接定位教材知识点讲解。
- 自练补充回看讲解及跨单元下一知识点；本地存储失败时明确提示当前答案不会持久保存。
- 星级规则说明默认折叠，保留可展开查看。
- 桌面与手机统一五个学习入口，工具深链保留所属主导航高亮。

## 仍需独立实施的产品范围

原需求包括 Web OCR、生成式连续对话、语音、完整多科测评、真实教师送达与原生双端发布。这些不是界面调整即可完成的能力。当前三科自练保留浏览器草稿，不生成正式成绩；数学审核题库仍承载组卷、报告、证据和错题闭环。没有把这些尚未完成的能力标记为已实现。
