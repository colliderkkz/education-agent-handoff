# 小禾学伴实现计划与验收依据

## 部署目标修正（2026-10-26）

用户明确要求可安装的手机 App，Android 和 iOS 都要。后续以[双端实施计划](../../APP-实施计划.md)为交付计划；现有 Sites 网页作为教研与业务验证基础，不视为 App 已交付。用户以中国大陆用户为主，目前无 Expo、Apple Developer 或云服务账号，先进行本机试验，不以注册云账号为前置条件，本轮不发布云端新版。

本机完整 Xcode 和 iOS 模拟器运行时尚未安装，iOS 原生运行和安装包验收未完成。现有 Apple Command Line Tools 不等于完整 Xcode；macOS 26.5.1、Expo SDK 58 的工具链限制见[手机工程说明](../../xiaohe-mobile/README.md)。不承诺现有 Expo Go 可直接运行，也不要求用户立即注册账号或升级系统。

## 产品范围

依据上一级目录的《小禾学伴V2.pdf》《小禾学伴-手机端.pdf》《小禾学伴-管理端介绍.pptx》，最终目标为学生移动端、教研管理端和共享业务服务。原资料的 49 个移动界面/状态和 8 个管理界面属于功能范围，不强制每个状态单独一个 URL。

完整学习流程：课程上下文 → 拍题或作业 → 识别核对 → 解析/错因 → 题库组卷 → 在线作答或打印回传 → 帮助和独立证据 → 间隔新题复查 → 知识点反馈。内容流程：来源 → 校对 → 解法 → 独立审核 → 发布/停用/回滚。

## 实现阶段

1. 工程、学生端和管理端框架、数据契约。
2. 课程、题库、教学标注、内容版本、审核发布。
3. 组卷、换题、在线作答、草稿、报告、错题、证据。
4. 图片保存、人工核对、自动识别接入、打印/回传。
5. 题目上下文学伴、学习记忆、家长/教师关系与授权、求助。
6. 独立评估、试点部署、其他学科、语音、训练与数据集。

## 当前技术选择

使用 Sites 的 Vinext/React/TypeScript 模板，保持 Next.js App Router 结构。私有托管运行于 Cloudflare Worker，数据库使用 D1，图片使用 R2。当前试点按用户保存工作区文档并以 revision compare-and-swap 防止并发覆盖，上传元数据独立建表。与最初 PostgreSQL 建议不同，此选择适配已经建立的 Sites 托管；多学校规模化前需评估实体分表、配额与数据库迁移。

当前 Web 身份来自 Sites 登录。每个登录账号拥有自己的工作区，可通过邮箱绑定的一次性邀请授权学生、家长、教师、编辑、审核人。接口会按角色剔除未授权数据；App 需要另接独立身份服务，学校与班级组织模型仍未完成。

## 首版关键不变量

- 原始作答、识别核对、订正、提示、讲解与独立作答分别保存。
- 题目修改生成高于历史最高值的新版本并回草稿，归档实际存在的题目版本，试卷持有不可变快照，换题另存。本地内容包保存应用/撤回批次，按最近有效批次回退；不能补造升级前未保存的历史。
- 后端计算正确与帮助状态，客户端不能自行填写成绩或降低帮助级别。
- 已提交记录不可被重复提交或后续曝光改写。本人另行预览并确认历史删除后，选中作答正文物理移除，保留无正文凭据；报告分母排除已删除项。
- 纸面作答帮助情况默认为未知，不推断为独立完成。
- 星级只使用对应知识点的适格证据；演示历史不提高真实星级。
- 看过解析的题族不视为新题；未学或未发布内容不进入默认组卷。
- 作者不能审核自己的内容；审核与发布为不同动作。
- 图片与工作区访问验证身份归属；私人对话不进入导出的教学内容清单。
- 学伴固定原卷或题库版本及正文摘要，私有快照不进入学生投影；普通文本只记录，只有主动选择帮助才展示已有提示或解法。帮助曝光不得因删会话而撤销，不改已提交作答与历史评定。
- 呈现偏好只来自本人主动设置。会话删除前预览实际影响并绑定 revision；已删除请求只留无正文的幂等记录，重放不能恢复消息。手写求助摘要单独确认和保存，删私聊不等于撤回摘要。

领域测试验证计分、帮助等级、同题族、版本、审核分离、重复提交、题量缺口与星级证据。API 集成验证身份、真实持久化、文件访问和并发。浏览器验证完整练习、题库工作台、上传核对、打印，以及手机布局。生产构建与私有部署均须独立确认，不以开发服务器替代。

这个文件记录实施范围，不能单独作为功能完成的证据。实际进度以源码、测试与浏览器/部署结果为准。

## 本地内容包增量（2026-10-27）

教研端导出严格白名单 JSON，手机显式选择后预览与应用。Web 仅导出并只读展示归档/批次历史，没有内容包导入或回退操作入口。包不含学习档案/作答/照片/对话/评定规则；所有包为未签名、未验证的本地试用，自填作者/审核标识不是身份认证。内容摘要仅校验一致性，规范化题干与纯数字变式检测不能代替语义重复人工审查。题目 prerequisites 当前是文字说明，尚未建立可执行的前置知识图谱。

独立扩充包包含 9 题（8 个新结构候选、1 个沿用旧族的基础子任务），不自动 seed，不假称真人教研审核。算术测试与具体范围见根目录 `content-trial-notes.md`。自动化与设备证据分别记录，对应手机验收见[内容包验收记录](../../xiaohe-mobile/docs/content-trial-validation.md)。

## 本机学伴与可核对记忆增量（2026-10-27）

本轮已实现以下局部闭环，没有将整个 C01/C02/M02/M03 标记为完成：

- 固定原卷或题库版本的私人会话、一般学习记录、旧消息版本未知标识。显式选择提示/讲解/其他方法才引用保存的源解法；无源解法明确失败，不伪造生成式回复。
- 消息请求幂等、草稿保存与恢复、并发修改拒绝及未知结果重试；查看帮助同步在途同题族记录，已提交作答和原评定保持不变。
- 本人设置分步/紧凑呈现偏好，可新增、修改、删除，显示设置来源与时间，回复记录实际采用的偏好；不推断性格、能力或情绪。

- 本人手写求助摘要预览后确认，复制安全题目上下文，不附带完整私聊、草稿、偏好或照片。App 标记仅本机保存；Web 明示工作区共享范围，不发送外部通知。

## 学习历史删除增量（2026-10-27）

Web 本轮实现“我的 → 小禾记住了什么 → 管理与删除历史”，报告也可带入单条证据。只能选择已提交 Evidence；本人/所有者预览影响后绑定工作区 revision、digest 与稳定请求编号确认，家长、教师、编辑、审核人无删除权限。确认会移除所选答案与过程、错题、更正记录、受影响评定正文，以及本人明确关联原卷题目的会话和摘要；题库和原卷题目保留，未选照片保留，仍有引用的所选照片在预览中说明并保留。

当前/历史报告都无法取回已删正文，报告显示删除数量并排除分母；按剩余证据重新评定并使失效复查来源不可继续使用。保留无正文删除凭据及最小已见题族/帮助事实，不能借删除恢复新题资格。浏览器当前工作区/当前账号的相关草稿缓存会在确认状态后清理，延迟写入不能恢复已删记录。

照片删除任务与业务状态一起通过 D1 CAS 持久化。普通和教师材料 GET 在 R2 读取前后检查当前成员授权、上传登记与删除墓碑。确认后执行幂等回收，失败时保留任务或已完成 PUT 的暂存索引；重试仅使用服务器文件索引或严格校验过的服务端恢复元数据，不接收客户端 objectKey。新增 `drizzle/0002_history_upload_fence.sql`，本轮只通过 SQLite 迁移测试，未对现有开发数据库或线上执行迁移。

本轮 Web **220/220** 自动化测试、类型检查、lint（3 条既有图片优化 warning）及生产构建通过，日志与能力边界见[历史删除 Web 验证](history-web-validation.md)。本轮未启动 Web 服务、未做浏览器点击/窄屏验收、未部署；服务端文件 I/O 故障路径以可注入存储测试验证，不宣称实云 R2 验收。手机设备结果由手机工程的对应验收文档单独记录。

## 本机照片识别核对领域增量（2026-10-27）

新增可选识别档案：原图摘要与上传登记、不可被人工改字覆写的设备行文字/位置/实际置信度、逐题核对草稿、冻结候选及正式报告分别保存。所有 `recognition.*` 动作只允许可信本机上下文中的本人 student/owner，Web 请求不能用参数伪造设备来源。候选检索只提供安全元信息，保存时固定题目版本，续接时仍展示该版本题干与单位；正文或候选变化即清核对标记。

一次图多题可以只提交已核对条目，其余不匹配或不清楚内容保留草稿、不计分。入档按纸面自述处理，帮助状态未知，不计独立星级，不称教师核实。删除所选证据时清其人工正文、同图所有机器原文及全部未提交草稿；预览明确额外范围，未选已提交人工答案保留。原图仍按显式选择和剩余引用处理；已清理识别档案禁止重扫与迟到结果恢复。

当前 **237/237** 共享领域/Web 测试通过，其中新增识别回归 **17/17**；类型检查、全仓 lint（0 错误，3 条既有图片优化 warning）、生产构建与 diff 检查通过，详见[领域验证](recognition-validation.md)。本轮没有 Web OCR 接通、浏览器实测或云发布；设备首次离线试验的 R8 问题及后续修复验收由手机工程另记，不能将合成行测试写成设备识别成功。多页/裁切/自动题块切分、数学 OCR、自动同题判断与服务端识别仍在后续范围。
