# 浏览器图片文字识别

学生拍照页在图片保存后可识别文字；单题模式可将一段文字带入题库检索。教研工作台的“提取与校对”可选择本地图片，识别后自动批量写入题库草稿，来源范围、答案、知识点、难度和教学内容仍须填写并审核。重复保存同一张图片的同一识别结果使用稳定请求编号，不会重复导入；改动图片或识别结果可能产生新的草稿。

识别使用 Tesseract.js 7 和简体中文、英文 LSTM 模型，图片在浏览器内处理。学生拍照页的图片仍按原有流程保存到工作区；教研页面选择的图片仅用于当前页面，不自动上传或保存，题目草稿记录文件名。识别有题号时忽略题号前的页眉；没有题号时整段作为一题。自动分组可能不正确，逐题打开草稿核对；公式、图形、手写、复杂排版、PDF 和识别准确率尚未验证。

`npm run dev` 和 `npm run build` 会自动执行 `scripts/prepare-ocr-assets.mjs`，从锁定的 npm 依赖复制模型、worker 和 WASM 运行时代码至忽略的 `public/ocr/`。生产构建须先安装依赖并使用这些脚本；勿依赖外部 CDN。浏览器须支持 WebAssembly、Web Worker 和 createImageBitmap。文件限制为 10 MiB、2400 万像素，每批最多 20 题、每题 2000 字。识别文本不会自动生成成绩、报告或发布题目。

依赖及模型许可请在发布前核对：Tesseract.js 和 tesseract.js-core 的 npm 包含各自许可，`@tesseract.js-data/chi_sim` 与 `@tesseract.js-data/eng` 的模型及来源信息见相应包。浏览器识别结果可能出现漏字、数字和单位错误，必须逐项校对。
