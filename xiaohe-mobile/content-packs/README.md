# 可选本地试用题包

本目录存放可导入本机的题库内容包。文件不会自动应用，也不包含学生作答、照片、聊天或评定规则。

| 文件 | 内容 |
|---|---|
| `xiaohe-basic-trial-v1.json` | 9 道四年级数学基础试用题（原试用包，覆盖除法、周长面积和三位数乘两位数） |
| `xiaohe-chinese-v1-1..4.json` | 语文静态内容库（四年级上册 19 个知识点，608 题），按 200 题/包切分 |
| `xiaohe-math-v1-1..4.json` | 数学静态内容库（四年级上册 22 个知识点，704 题），按 200 题/包切分 |
| `xiaohe-english-v1-1..3.json` | 英语静态内容库（四年级上册 16 个知识点，512 题），按 200 题/包切分 |
| `xiaohe-junior-math-v1-1..4.json` | 上海初中数学（33 个知识点，660 题，按中考考纲编写），按 200 题/包切分 |
| `xiaohe-senior-math-v1-1..2.json` | 上海高中数学（15 个知识点，300 题，按高考考纲编写），按 200 题/包切分 |

静态内容库包由教研工程的静态题库切出，覆盖小学四年级上册三科 57 个知识点与上海初高中 48 个数学知识点，共 2784 道原创题。包上限是 200 项 / 500 KiB，因此一个学科会切成多个包，需要全部导入才能覆盖该学科。

初中与高中包的 `courseScope` 分别声明为「九年级 · 数学」与「高三 · 数学」，与小学包的「四年级 · 语文/数学/英语」区分开；导入时按包的课程范围校验，不会混进同一个学习空间。导入包时会按教材目录在本机建立对应的知识点条目 —— 不用再单独解锁就能直接练。

## 在 Android 试用

1. 将 JSON 复制到手机或模拟器的“下载 / Downloads”目录。
2. 打开小禾学伴“我的 → 管理本机题库内容包”，选择该文件。
3. 核对预览中的“新增 N 题”及来源说明，再点击“确认应用到本机题库”。

重复选择同一包不会重复导入。可填写原因回退最近一个仍生效的批次；原有试卷、作答和照片保留。已经回退的同一文件不会被再次启用，后续更正应制作明确的新版本内容包。

## 内容范围

静态内容库按教材单元编写：小学每个知识点 30 道原创题（基础 10 / 应用 10 / 迁移 10），上海初高中每个知识点 15 道（基础 5 / 应用 5 / 迁移 5）。每道题是一个独立题族 —— 同一题族只计第一次独立新题，所以「30 道」不等于「30 次可独立作答的练习」。

上海初高中的题目按上海市中考/高考考纲的**考点与题型结构**原创编写，**不是历年真题**，也不照抄教材原文；出处逐题写在包内的 `source` / `sourceScope` 字段里。

题目的使用范围与有效性说明写在包内的 `sourceScope` 字段。包内作者与审核标识为机器流程标识（`bank-author-*` / `bank-check-*`），**不是真人身份认证**；包固定声明 `unsigned` / `unvalidated-trial`，SHA-256 摘要仅用于内容一致性核对。

包内题目带 `image` 字段时指向教研工程的 `/illustrations/...` 路径，**本机 App 尚不能显示这些配图**（图片随 App 打包的适配尚未完成）。上海初高中包目前没有配图，条件都写在题干里。

带「A．B．C．D．」选项的题目在本机 App 里按单选作答，提交的答案是选项字母。

静态内容库源文件位于相邻教研工程的 `content/bank/`。在教研工程运行 `node --experimental-strip-types scripts/export-bank-packages.mjs` 可重新生成本目录下的静态库包；运行 `node --experimental-strip-types scripts/export-trial-content.mjs` 重新生成试用包。两者都不会改写学习档案。
