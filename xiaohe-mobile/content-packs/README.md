# 可选本地试用题包

`xiaohe-basic-trial-v1.json` 含 9 道四年级数学基础试用题，覆盖除法、周长面积和三位数乘两位数。文件不会自动应用，也不包含学生作答、照片、聊天或评定规则。

## 在 Android 试用

1. 将 JSON 复制到手机或模拟器的“下载 / Downloads”目录。
2. 打开小禾学伴“我的 → 管理本机题库内容包”，选择该文件。
3. 核对预览中的“新增 9 题”及来源说明，再点击“确认应用到本机题库”。

重复选择同一包不会重复导入。可填写原因回退最近一个仍生效的批次；原有试卷、作答和照片保留。已经回退的同一文件不会被再次启用，后续更正应制作明确的新版本内容包。

## 内容范围

这 9 题包含 8 个新结构候选和 1 个沿用旧题族的基础子任务，不等于 9 个新题族。选项编号辨认题不代表完整计算能力，先修条件仅为文字说明，不能保证所有旧档案都具备继续升星所需的新题资格。

题目由 AI 起草，算术与结构清单经过独立脚本检查，尚未人工教研验证。包内作者和审核标识为机器流程标识，不是真人身份认证。包固定声明 `unsigned` / `unvalidated-trial`；SHA-256 摘要仅用于内容一致性核对。

源文件与具体范围位于相邻教研工程的 `lib/trial-content.ts` 和 `content-trial-notes.md`。在教研工程运行 `node --experimental-strip-types scripts/export-trial-content.mjs` 可重新生成本文件；不会改写学习档案。
