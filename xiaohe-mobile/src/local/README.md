# 本机学习引擎

> 交接校正：本文件“没有 OCR”描述属于早期里程碑；当前 Android 已接入本机 OCR，iOS 仅有待验收模块源码，见 [模块说明](../../modules/xiaohe-ocr/README.md) 与主 README。

当前版本无需账号、网络服务或平台凭证。一台设备保存一个学习档案；`local-…` 只是该安装的标识，不是云端身份。SQLite 文件 `xiaohe-learning-local-v1.db` 保存在 App 的应用存储中。照片由页面先复制到应用 Documents 目录，再通过 `local.upload` 登记。没有同步、OCR、云端教师收件箱或大模型调用；卸载 App 或清理应用数据可能丢失本机内容。

UI 通过 `LearningProvider` / `useLearning()` 使用 `state/loading/error/busy/act/reload`。引擎内部保留完整题目快照，所有返回状态均调用学生权限投影；提示和解析在相应操作确认保存后才开放。记录在设备本地，投影用于维持正常学习流程，不是对设备拥有者的防篡改或加密保护。

初始数据有 30 道原创数学样题和知识点说明；没有演示作答、报告、错题、聊天或学习证据。五星配置明确为未验证的本地试用，评定保留规则版本、条件和逐题依据。查看提示或解法只记录题族曝光，实际提交才评定；订正不增加独立证据，已提交试卷不可覆盖。真实提交生成间隔复查计划，开卷与计分使用一致的有效间隔，排除全部历史已见题族。题量不足会明确报错，不靠重复旧题凑新题证据。

旧档案缺少 mastery 时，reload 先完整校验，再保留旧评定并仅更新逐字段匹配的未编辑原始样题，revision 加一后通过同一 CAS 写入。失败时原数据不变、不给界面发布半套升级；原始作答、冻结试卷、照片、纸面回传不修改。旧证据缺少的教学标签不回填。每知识点只有三道基础样题，旧档案耗尽基础题族后可能无法达到新规则三星以上，可通过明确选择的本地内容包扩充；仍需充分且经人工教研确认的题族。

`act` 把输入快照按调用顺序排队，SQLite 使用 revision 条件更新；成功落盘后才发布新状态。持久化结果不明时回读确认：完全匹配则成功，旧记录不变则允许重试，无法确认或被其他写入改动则停止写入，等待 `reload`。损坏、版本不支持或关联缺失的数据保留原样，不静默清空。照片登记重试使用相同 id；调用方不要因一次不确定错误就删除照片。

纯业务源码复制在 `shared/`，运行时不依赖相邻 Web 工程。更新时执行 `node scripts/sync-local-domain.mjs`，只给 `structuredClone` 增加兼容 Hermes 的 JSON 数据克隆导入，其余业务源码逐字复制。`node scripts/sync-local-domain.mjs --check` 检查来源散列与生成文件。`node --experimental-strip-types --test tests/local-engine.test.mjs` 覆盖串行队列、重启草稿、提示曝光、提交幂等、失败保存、损坏保护、权限和真实 SQLite CAS。

内容包共享领域实现位于 `shared/server/content.ts`。本机 `local.content.preview/apply/rollback` 与正式学生角色的领域权限分开；学生投影无归档正文，仅保留数量/版本/批次摘要。首次缺少 content 时一次 CAS 归档现有题库和原卷，不补造缺失历史。已存在内容档案后不再运行样题自动替换，防止重启恢复撤回内容。版本摘要与批次引用在每次读写时校验，失败不重置。

系统 DocumentPicker 显式选文件后复制到缓存；FileHandle 逐块有界读取真实字节数，拒绝无效 UTF-8、空包、超限、未知字段和不匹配摘要。包在内存中预览，绑定当前 revision 与内容摘要；原始 JSON 不写入学习记录，版本正文与批次以一次事务保存。

历史删除使用共享 `history.delete.preview/confirm`，仅允许明确选中的已提交 Evidence。`historyDeletion` 保存无正文凭据、精确复查来源快照、已见资格事实与照片任务；严格校验只允许对应凭据证明的答案缺项。普通提交和证据更正仍不能覆盖原始提交，显式删除是有影响预览的独立流程。

引擎先 CAS 保存删除与 pending 文件任务，再调用运行时注入的私有照片清理。未知提交必须重读，清理及 ack 失败不恢复原内容；reload 与 `history.files.retry` 幂等继续任务。完成任务仍保留文件身份，阻止别名登记和恢复扫描；只删除当前 App `xiaohe-images` 自有文件，旧不受支持路径显示 pending，不删除相册或任意路径。不会承诺擦除 SQLite 历史页或外部备份。
