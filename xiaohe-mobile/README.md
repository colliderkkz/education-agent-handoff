## 本地试用方式

手机客户端使用 Expo SDK 58 / React Native 原生组件，学习数据保存在本机 SQLite，照片保存在 App 私有目录。无需业务账号或云服务器。不同设备之间暂不自动同步，卸载或清除 App 数据可能丢失记录。

本地版用 30 道原创数学样题验证选知识点、组卷、换题、作答、草稿保存、提示与讲解、提交、报告和错题订正；没有预置虚假的学生成绩。相机和相册用于本机留存；Android 已接入设备端中文 OCR，识别文字仍须逐题人工核对，尚未接入生成式 AI 或语音。

已接入五星试用规则、逐次评定历史与间隔新题复查。1—2 星依据实际使用讲解或提示后的作答，3—5 星分别要求基础独立、稳定的不同情境应用和到期迁移新题。查看解析本身不加星；纸面自述不作为已验证的掌握证据。默认间隔为三天，数值阈值和题目教学标注都未经过教学验证，不能作为正式学业评价。

旧版本首次打开会进行一次原子升级：保留原有星级、作答、冻结试卷和照片，记录旧版评定依据；只更新未编辑的原始样题，不补猜旧证据缺失的标签。按新规则重评可能得到不同星级或待评估，旧结果仍可查看。

随 App 出厂的小样题很少（每个知识点只有 3 道基础、5 道应用和 2 道迁移样题），真正可练的题库靠内容包导入：教研工程导出的静态库覆盖小学四年级 57 个知识点（每点 32 道）与上海初高中 48 个知识点（每点 20 道），共 2784 道原创题、2784 个独立题族、17 个内容包（另有一个 9 题的试用包）。导入后系统会按教材目录在本机建立对应的知识点条目，不用再单独解锁就能练。历史已见题族不能重新作为独立新题；旧档案已做完基础题或新用户用过帮助后，可能不足以满足新规则三星以上。导入前可先预览新增、更新与停用数量，再确认应用。教研端导出与手机导入通过本地 JSON 文件完成，不自动同步。不能通过换题号或重置档案冒充掌握进步。

**学段、真题与错因（与网页端同一份规则）**：首页列出小学四年级、上海初中、上海高中三条学段线，点一行切换学段，练习页与知识地图跟着换范围；一张卷子只能包含同一学科、同一学段，混选会被明确拒绝。练习页可按「卷面结构」出卷（上海中考数学 25 题结构等，卷面结构只决定题型比例，题量仍按你选的数量）。「真题考情与出处索引」页给出官方公布的卷面结构与考点出处（年份 → 题号 → 考点），**不收录真题原文** —— 上海市教育考试院只发布试卷的「专家点评」，原卷请通过学校或正规渠道获取。错题本可给每道错题标错因（概念不清 / 计算失误 / 审题偏差 / 步骤遗漏 / 公式记错），标过的错题按原因聚成「按错因看」，每组能直接出「按这组错因练 N 道」—— 同一题族 14 天内不重复出题，所以组卷范围会带上同单元的已解锁知识点。错因由学生自己选，系统不替他猜。

现在还可从练习详情导出 **A4 学生卷或独立答案解析卷**，在系统中预览、打印、分享。纸面做完后可多选照片，逐题手工录入并确认原答案和单位；回传绑定原试卷版本，提交前可归档保留已有在线草稿。学生卷不含答案；导出解析卷会记录已看过讲解。纸面自述“独立完成”保留为未核实，不直接增加独立掌握证据。

本机题库和判分用于功能试验，不能作为正式可信测评或多账号权限实现。后续上线时，身份、答案、判分和授权须迁回独立业务 API。

## 照片识别与逐题核对

拍题页选中已保存照片后，点“识别文字与逐题核对”。Android 使用随安装包附带的中文模型，已在断网状态下完成真实识别。选择文字行组成一道题，填写纸上的原始答案，对照图片选择同一道题的题库候选；保存草稿后，再分别确认题干、原答案、同题关系与单位，选择本次要入档的题目。未匹配或未核对的题留在草稿中，不会自动算错。

机器原文、人工修改及固定题库版本分别保存。识别错误不会自动变成学习成绩；纸面帮助情况保持未核实。历史删除会说明并清除同图机器文字和未提交草稿，其他未选的已提交记录保留。iOS 已接入 Vision 模块源码，但尚未编译和运行验收。完整证据和边界见[照片识别验收](docs/ocr-trial-validation.md)。

## 本机学伴与学习记忆

首页“和小禾一起理思路”、我的“继续我的学伴对话”可打开会话；练习、拍题、报告和错题可带具体题目进入。题目会话固定原卷或进入时的题库版本，更新题库不会换掉正在讨论的题目。从练习进入前先保存答案草稿。早期消息未记录版本时会明确标为未知，不补猜题目。

普通文字只记为问题笔记。只有明确选择并确认“给我提示”“完整讲解”或“换一种讲法”，才引用该版本题库内容并记录帮助使用；当前没有生成式 AI。草稿自动保存并可在重启后续写，保存失败或冲突时可重读核对。删除会话前会显示影响，确认后从当前档案移除消息和草稿；已发生的帮助事实、原作答及另存摘要保留，不会因此变回独立作答。

“我的 → 查看学习记忆与本人偏好”区分本人档案、课程配置和作答证据。讲解呈现方式由本人明确选择、修改或删除，后续题库回应会采用该选择；不会从私聊推断性格或能力。

报告、错题和学习记忆现可进入“核对作答证据”：选择答案录入、帮助标记、知识点或有效状态，填写原因，主动选择已有原稿。先保存申请，再预览影响并确认。当前报告、错题、星级与复查来源统一更新，原始提交和旧评定保留；后来学会后的新答案仍应使用“学习订正”。本机决定未经教师复核，不发送给老师，也不凭本人自述增加掌握证据。标记无效只排除当前统计，真实删除使用下述历史管理入口。

“我的／学习记忆 → 管理与删除历史作答”支持逐条或全选已提交作答，先预览报告、错题、旧评定、复查及本人关联会话／摘要的影响，再明确确认。原答案和过程真正从当前档案移除，教学题目、空白原卷和未选记录保留。照片需要另行选择；共享引用存在时保留，清理失败显示待重试，旧登记和恢复扫描不能把照片重新加入。全部删除后显示“当前无可统计作答”，不会显示 0/0 或学习评价。未完成草稿和账号整体删除不属于此入口。详见[历史删除验收](docs/history-trial-validation.md)。

求助摘要须手工填写、预览并单独确认，只另存所选题目及来源和摘要，不自动附完整对话。当前显示“本机保存 · 尚未发送”，尚无在线教师收件服务。摘要草稿在确认前只留本页，未保存时离开会提醒；这与可重启恢复的会话草稿不同。

## 本地题库内容包

“我的 → 题库内容包”可选择教研端导出的 JSON（最多 500 KiB、200 项），先查看安全摘要，再确认应用。文件不含学生作答、照片、聊天或评定规则。导入是本机内容维护，不是云端发布；所有包都明确未签名、教学有效性未验证，自填作者/审核标识不代表真人身份认证。

示例文件为 `content-packs/xiaohe-basic-trial-v1.json`，可复制到 Android 的下载目录后选择导入。它含 9 道基础试用题：8 个新结构候选与 1 个沿用旧题族的前置子任务；选项编号辨认题不代表完整计算能力。算术与结构清单经过自动测试，尚未人工教研审核。文件不会自动应用，也不能保证所有旧档案都满足新题星级条件。

首次升级会归档当前题库和冻结试卷实际存在的版本。导入校验通过后整批保存；重复导入不重复写入，同版本不同正文、同题换编号、仅换数字另建题族会拒绝。语义改写与跨场景近重复仍需教研判断，不能仅靠摘要全面识别。

批次回退须填写原因，只允许最近一个有效批次。回退切换未来可用题目，保留历史试卷、作答、照片、帮助与评定；已经回退的同一文件不会因再次导入而重新启用。规则和学生档案不随题库导出。完整原文件配对导入、校对与教研验证仍按总计划继续。

## 启动开发服务

在此目录运行：

```sh
npm install
npm start -- --lan
```

也可双击 `启动手机调试.command`。电脑和手机须处于同一局域网。

- Android：日常本机试用使用开头的独立 APK 启动方式。本项目包含自定义 OCR 原生模块，完整功能需要本机 APK 或自定义开发构建，Expo Go 不包含该模块。
- iPhone：尚未安装或运行验证。新增原生模块需要完整构建，不能用 Expo Go 扫码或 JavaScript 导出代替。当前本地试验不要求注册 Expo 或 Apple Developer 账号。

iOS 工具链核验时，本机为 macOS 26.5.1。按 [Apple 系统要求](https://developer.apple.com/xcode/system-requirements)，Xcode 27 / 27.1 需要 macOS 26.6 或更高版本；Xcode 26.6 支持当前系统。项目使用的 Expo SDK 58 官方默认云端 iOS 构建环境为 Xcode 27.1，尚未实测本项目在 Xcode 26.6 上的兼容性，不能仅因它支持当前 macOS 就视为可用。完整 Xcode 的[官方获取渠道](https://developer.apple.com/xcode/resources/)包括 Mac App Store；旧版下载需登录 Apple Account，但不要求付费开发者会员。本次没有确认无需 Apple 账号的官方完整工具链下载路径。

iOS 保留本机编译与试验目标，当前无需立即注册账号或升级系统。待具备合适工具链后，再单独验收原生构建、启动、SQLite 恢复和图片权限；目前 iOS 代码导出通过不代表已经获得可运行的模拟器 App 或可安装的 iPhone App。模拟器构建也不能直接安装到 iPhone；真机本地安装另需 Apple Account 签名，可使用有有效期限制的[免费 Personal Team](https://developer.apple.com/help/account/basics/about-your-developer-account)。

## 本机 Android APK

项目提供 `npm run android:apk`，使用 Expo 自动生成的 Android 工程、Gradle 和开发签名构建包含 JS 的 ARM64 本地试用 APK。它不依赖 Metro，不能作为商店正式发布包。

工具链优先读取 `JAVA_HOME` / `ANDROID_HOME`；未设置时使用本项目忽略目录 `outputs/toolchain/`。当前配置为 JDK 17、Android Platform 37.0、Build Tools 37、NDK 27.1.12297006、CMake 3.22.1。它们与系统应用、默认 Java 和 shell 配置分离。

```sh
npm run android:apk
```

已有生成的 Android 工程，且**仅修改 JS / TS** 时，可复用原生工程快速重新构建；本机一次实测约 17 秒，耗时会随机器和缓存变化：

```sh
npm run android:apk -- --reuse-native
```

原生配置、插件或依赖有变化时，使用默认完整命令 `npm run android:apk`，不要复用旧原生工程。

当前包含针对 `expo-print 58.0.7` 的 Android 文件渲染生命周期补丁。安装依赖和构建前都会校验版本与原文件哈希，遇到未知变更会停止；依赖升级时须按[补丁维护说明](patches/expo-print/README.md)审查，不能跳过校验。

中文 OCR 模块固定了反射注册器构造函数的压缩保留规则。构建还会核对本地模块、R8 任务图和实际合并清单／映射，检查失败不会复制新 APK；不得通过关闭压缩绕过。

成功时生成 `outputs/xiaohe-local-trial-arm64.apk` 与 `outputs/android-build.json`。当前 APK 已实际构建并在本机安卓模拟器安装；构建元数据记录构建当时的状态，不替代后续设备验收记录。后续修改源码后需重新构建 APK，已安装的独立包不会从 Metro 自动更新。构建生成的 `android/` 不手工编辑、不提交。

Android 模拟器只能验证相应 Android 环境；iPhone 相机、键盘、安全区和签名仍需单独测试。
