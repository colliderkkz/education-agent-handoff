# 已提交学习历史删除：本机试用验收

日期：2026-10-27。用户要求 Android 和 iOS App、中国大陆用户为主、当前只在本地试验，不注册平台或部署云服务。本轮实现 M02 中已提交作答历史的选择、删除影响说明和实际删除；不代表全部产品范围完成。

## 交付与入口

- 我的／学习记忆 → 管理与删除历史作答；报告可预选本次作答，逐题证据页可预选一题。
- 逐条或全选已提交作答 → 查看影响 → 照片另行选择并重新预览 → 明确确认 → 删除结果及照片清理状态。
- 未完成草稿不在这个入口中。教学题库、空白原卷、题面及解析 PDF 保留；用户未选的作答保留。未选择或仍有其他引用的照片保留，预览说明原因。照片列表包含本机已登记照片，不以旧自由文字猜测其关联。
- 删除真实移除当前档案里的原答案、过程、对应纸面录入和归档在线答案、错题、更正链、本人明确关联原卷题目的会话与求助摘要。受影响旧评定正文移除，当前结果重算；无结构学习日志及旧规则试算的额外清理范围在预览中说明。
- 保留无作答正文的删除凭据和最少已见题族／帮助资格事实。删除不能让旧题变成独立新题。尚未开始且失去来源的复查不能启动，已产生的后续复查作答不级联删除。
- 删除后原报告标明缺项，删除项排除分母；全部删除显示“作答已全部删除／当前无可统计作答”，不显示 0/0 或表现评价。标记无效与删除保持区别。

## 持久化和剩余边界

SQLite CAS 先保存删除结果及文件任务，随后仅清理 App 自有照片目录。未知提交不能先删文件；物理清理或 ack 失败保持 pending，重启或“重试清理本机照片”继续处理。完成后仍保留无正文文件身份，阻止旧登记和恢复扫描重新加入。旧页面已经保存且被删除的字段清空，真正未保存的输入仅供复制，不能写回旧提交。

这不是账号注销或整机安全擦除。系统相册原件、已分享文件、系统备份及 SQLite 历史页不在承诺删除范围；普通或题库会话因缺少明确原卷关联不自动删除。未完成草稿、独立照片管理、其他人私聊和账号整体删除没有被此入口一并实现。文件故障与并发组合主要由自动化覆盖，未在设备上破坏系统存储制造全部故障。

真实安卓手机、多品牌系统、iOS 原生安装和运行、正式身份／同步、真实 OCR／模型／语音、教师送达回复与原生多人协作、充分教研题库和商店发布继续按总计划推进。本轮未推送、未云发布。
