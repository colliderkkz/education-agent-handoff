## 本轮功能与边界

五星规则分别对应讲解后完成、提示后完成、基础独立、不同情境稳定应用、间隔后独立迁移。未学与证据不足独立表示。每次评定保存当时规则、条件、采用/排除证据、前后结果；手动重评只追加记录。一个错误不骤降，重复点击重评不能反复消费同一批失败。

默认阈值明确为未验证的试用配置，内置规则不伪造人工审核人。教研 Web 支持规则草稿、参数校验、独立审核、最新试算后发布/切回、停用非当前版本；本机 App 与 Web 暂不自动同步题库、规则或档案。完整 Web 验证范围见 [Web 验收记录](../../xiaohe-app/docs/mastery-web-validation.md)。

真实提交可生成复查计划，包括受帮助完成与纸面核对；安排复查不等于获得独立掌握证据。开卷只选全部历史未见的迁移题族，可选 1 或 2 题。题量不足时保留计划并说明原因。规则延长间隔时，开卷和五星计分共用有效日期，原计划日期保留；已经开始的卷仍可继续，不另造新卷。复查卷固定题序，不允许换题。

30 道题是原创数学演示内容，每个知识点仅 3 基础、5 应用、2 迁移。旧档案已做完基础题或新用户使用过帮助后，可能没有足够新题族继续达到三星以上。已明确记录这个产品限制；后续需要真正扩充不同结构的新题及内容同步，不能改题号、清空用户历史或换数字冒充新题。题目教学标注也未经过教学验证。

## 旧数据升级

首次读取旧档案，先校验完整性，再通过 revision CAS 一次提交迁移。保留旧星级与其规则说明，只升级逐字段符合已知原始样题的当前题库条目；自定义题、删除过的旧题、冻结原卷和旧证据不覆盖。不会为旧证据补猜任务类型、情境或来源。

对上一版原生纸面回传验收的真实存储备份进行升级：revision 47 → 48，24 → 30 道题，添加三条旧版评定留档。原卷、作答、证据、照片引用、纸面回传、知识点旧结果逐字段及 SHA-256 保持一致。照片实际文件也留在原备份中；升级只处理档案记录。

磁盘失败时原字节保留且不发布半套新状态；重新读取可重试。已提交但原生回复丢失时由精确回读确认成功。并发 CAS 冲突不覆盖另一写入者。
