# 真实照片 OCR 与逐题核对：本机试用验收

日期：2026-10-27。面向 Android / iOS App、中国大陆用户，当前只做本地试验。本轮接入真实设备文字识别、人工核对草稿、部分入档及历史删除联动；没有注册平台、云发布或新增在线识别服务。

## 使用方式与交付

双击 `启动安卓试用.command`。在拍题页拍照或选择图片，保存后点“识别文字与逐题核对”。选择原文行组成一道题，填写纸上原始答案，人工确认题库候选确为同题。先保存草稿，再分别确认题干、原答案、同题关系和单位，保存核对状态后选择本次入档题目。未匹配题保留草稿，不计错题。

## 设备流程与包版本边界

使用 Android API 36 ARM64 独立 QA 模拟器，合成原创打印题与纯白图片均不含真实学生信息。首次运行识别之前即开启飞行模式、关闭 Wi-Fi 和移动数据；验收结束读取仍为 `1 / 0 / 0`。这证明本次识别可离线执行，不是对 SDK 永不联网的承诺。

1. 旧 QA 档案 revision 47，首次升级仅加入空识别容器及迁移事件，原有内容、冻结试卷、作答元数据和删除记录保留。经系统图片选择器选图，明确保存私有副本，revision 49；没有通过向数据库注入识别结果完成 UI 验收。
2. 第一候选包 `eb55ec9eea102e00f606c086392ec6d525c556c3d3d7627c17240a8f3335efb4` 实际失败：R8 移除了三种 ML Kit 注册器的反射无参构造函数，logcat 为 `NoSuchMethodException`。失败时原图保留，未创建 OCR 记录、作答或成绩。
3. 修复包 `c31108174aaf85aa23bde4893aae7b24a79e87ff980cec56dfd182c3710e8b69` 首次离线真实识别得到 10 行中文，保存原图摘要、引擎版本、尺寸和归一化位置，revision 51。ML Kit 未提供可靠行置信度，全部为 null。真实结果有“满→滿”“答案→苔案”和漏“几”等现象，不能当作正确率或数学理解能力证明。
4. 通过实际界面创建三条草稿：原题 1 选择第 2、3 行，手工输入答案 14；原题 2 选择第 5 行，输入纸上的错误答案 13；分别人工选择题库同题 v2，先保存再勾选四项并保存。原题 3 选择第 7 行、输入 11，没有选择返回的不同题候选，保留未核对草稿。revision 56。查找候选不会自动判断同题；第三题的漏字也没有被宣称已核对。
5. 验收包 `94841613079a3f68478949d82f2a9bae7e61fbb08af11412bf77fdf8d3355e61` 覆盖安装后，完整 revision 56 档案相等，冷启动能恢复三条草稿与核对标记。仅选择前两题提交，revision 57：报告 **1/2**，一条错题；两条原始证据均为 `help=unknown / eligible=false`，独立答对 0，第三题仍为草稿。机器原文保持不变。
6. 同包实测硬件返回键：编辑第三题题号后，第一次返回收起键盘，再次返回提示先保存，页面与输入保留；明确放弃本页修改后，已保存的题号仍为 3。这不承诺拦截 Home、系统杀进程或保存尚未提交的页面输入。
7. 通过系统选择器保存纯白图片并真实识别，返回 0 行，界面提示补拍或手工建立草稿，未新增报告、作答或错题。再次识别打印图得到相同 10 行，单独保存为第二次运行，原提交与第三题草稿不变，revision 62。

## 自动化与构建

手机工程 **229/229** 测试、typecheck、lint、15 个共享源码及 SHA-256 校验、Android 独立 APK 构建、Android / iOS Hermes 导出通过。新增覆盖本机原子保存、失败与未知提交、并发删除、固定候选版本、部分提交、草稿核对失效、历史清理与恢复保护；实际 React 组件 VM 覆盖保存重试、晚到输入、外部修改、根页面硬件返回与焦点清理。iOS 仅通过模块自动链接、Swift 语法、podspec 语法与 JS 导出，不代表 iOS 原生构建或运行成功。

Android consumer rules 仅保留三个实际 ML Kit 注册器及其 public 无参构造函数，没有关闭 R8。构建脚本检查本地模块源码与 R8 在 APK 任务图中，并从实际合并清单和 mapping 动态核验注册器，失败时拒绝复制新 APK。四项回归覆盖删除构造函数、混淆类名、误用别类内联帧和缺失模块；真实 release 输出及构建均通过。

共享领域 **237/237** 测试及生产构建结果见 [共享验证记录](../../xiaohe-app/docs/recognition-validation.md)；最后提示文案调整另外通过识别／历史删除 **29/29** 定向测试。本轮没有启动 Web 服务或做浏览器验收。

```sh
npm test

# 原生模块已生成且仅更新 JS/TS 后：
npm run android:apk -- --reuse-native

```

验收结束后关闭了独立无界面 QA 模拟器，日常试用模拟器继续运行。

本机证据在忽略目录 `outputs/qa/`：`ocr-installed-verification.json`、`ocr-device-verification.json`、`ocr-*-snapshot.py` 及独立快照/tar；`ocr-final-report.png`、`ocr-final-partial-submitted.png`、`ocr-final-hardware-back-guard.png`、`ocr-final-real-lines.png`、`ocr-final-redacted-cold.png`、`ocr-delivery-cold-report.png`、`ocr-delivery-empty-result.png`；测试、导出、构建和签名日志均以 `ocr-` 开头。早期 `ocr-offline-first-result.png` 是失败记录，不能作为成功证据。报告和部分入档截图已人工查看布局。

## 尚未完成的范围

多页导入、裁切旋转排序、自动题块切分、OCR 辅助已有原卷回传、可靠公式/竖式/手写答案结构化识别、自动同题判断仍待实现。真实安卓手机、多品牌兼容性、拍摄质量、90°/镜像与复杂图片组合、底层超时/后台/内存故障以及 iOS 原生运行仍待设备验收，不能由上述打印样图或自动化测试替代。未独立测量原生识别耗时或评估识别准确率。

本地题库只有试用样题；未知题保留草稿，不生成答案或假成绩。识别草稿需显式保存，保存成功才承诺冷启动恢复。历史删除是当前档案清理，系统相册、外部分享、系统备份及 SQLite 历史页不在安全擦除承诺内。完整产品、云服务和双端发布继续按总计划推进，本轮未推送或发布。
